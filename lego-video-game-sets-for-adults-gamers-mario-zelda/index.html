How to pick a LEGO video game set

A few quick tips before you buy:

  • Ask which console they grew up with: Atari for the earliest gamers, NES for '80s kids, Game Boy and Super Mario 64 for the '90s, Zelda and Pokémon for long-time Nintendo fans.
  • Display or play: most of these are 18+ display models. For a kid, the Creator 3-in-1 Retro Gaming Console or the Animal Crossing set are easier builds.
  • Start a gaming shelf: the Game Boy, NES and Atari sets look great side by side, so one makes an easy gift every year.
  • Retired sets: the NES, Atari, Sonic and Question Mark Block sets are retired and sold by third-party sellers. Check the seller, ratings and return policy before buying.
Gift tip: pair a set with a game from the same series. A LEGO Game Boy plus a retro handheld game, or a Zelda set with a Zelda game, is a gift they'll remember.
